Введение

В предыдущем посте я разбирала как работает тест Стьюдента и тест Велча на больших выборках (n = 1000–10000), в случае неравных дисперсий и размеров выборок. Краткий вывод: тест Велча надёжнее при неравных дисперсиях и разных размерах выборок, так как лучше контролирует ошибку первого рода.

Но в научных исследованиях, например в биологии, медицине выборки обычно не такие большие, может быть всего 5–30 наблюдений на группу. В прошлый раз обещала рассмотреть отдельно, как работают тесты на малых выборках. Здесь я подготовила интерактивные симуляции, которые работают прямо в браузере. Можно менять параметры и наблюдать, как это влияет на ошибку I рода и мощность тестов.

NoteНапоминание

Ошибка I рода — вероятность найти различия, когда их нет (ложноположительный результат). Должна быть ≈ заданному уровню α (обычно 0.05). Подробнее писала здесь.

Мощность (1−β) — вероятность найти различия, когда они действительно есть. Чем выше, тем лучше (обычно стараются иметь уровень мощности не меньше 0.8).

Надежный статистический тест должен строго контролировать ошибку I рода на уровне значимости α и при этом обладать высокой мощностью для обнаружения реального эффекта.

Немного формул

Тест Стьюдента

Вычисление t-статистики:

\[ t = \frac{\overline{X}_1 - \overline{X}_2}{s_p\sqrt{\frac{1}{n_1} + \frac{1}{n_2}}}, \quad s_p = \sqrt{\frac{(n_1 - 1)s_1^2 + (n_2 - 1)s_2^2}{n_1 + n_2 - 2}} \]

Количество степеней свободы: \(df = n_1 + n_2 - 2\)

Тест Велча

Вычисление t-статистики:

\[ t = \frac{\overline{X}_1 - \overline{X}_2}{\sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}} \]

Количество степеней свободы:

\[ df = \frac{\left(\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}\right)^2}{\frac{(s_1^2/n_1)^2}{n_1-1} + \frac{(s_2^2/n_2)^2}{n_2-1}} \]

Тест Манна-Уитни

Непараметрический тест, основанный на рангах. Не требует нормальности распределения выборочных средних. Статистика \(U\) считается по числу пар \((x_i, y_j)\), где \(x_i > y_j\), и сравнивается с нормальным приближением при \(n_1, n_2 > 5\):

\[ z = \frac{|U - \frac{n_1 n_2}{2}| - 0.5}{\sqrt{\frac{n_1 n_2 (n_1 + n_2 + 1)}{12}}} \]

В числителе — поправка на непрерывность (−0.5): дискретная статистика \(U\) приближается непрерывным нормальным распределением. На очень малых выборках (n ≈ 5–6) точный тест Манна-Уитни из-за дискретности становится очень консервативным.

ImportantНулевая гипотеза Манна-Уитни не о равенстве средних

Напомню, что тест Манна-Уитни не сравнивает средние, однако из-за восприятия как непараметрического аналога теста Стьюдента может сложиться такое впечатление. Его нулевая гипотеза — это \(P(X > Y) = 0.5\), то есть «значения из одной группы не склонны быть систематически больше значений из другой». Только при дополнительном допущении одинаковой формы распределений это эквивалентно сравнению медиан (или сдвига, тот самый location shift).

Практическое следствие: если у групп разные дисперсии (разная форма), нулевая гипотеза Манна-Уитни может быть нарушена даже тогда, когда средние строго равны. Поэтому ложные срабатывания Манна-Уитни в гетероскедастичных сценариях — это не ошибка в обычном смысле: тест корректно улавливает, что распределения различаются по форме. Просто он отвечает на другой вопрос, чем t-тесты.

Отсюда важный антипаттерн. Многие при виде неравных дисперсий переходят на непараметрику, считая её «более устойчивой». Но Манн-Уитни не решает проблему гетероскедастичности — он на неё реагирует (даёт ложные срабатывания при равных средних). Если дисперсии разные, правильный инструмент — тест Велча, а не Манн-Уитни. Еще можно использовать тест Бруннера-Мюнцеля (Brunner-Munzel test).

NoteКоротко: как выбрать
  • Данные числовые, дисперсии могут различаться, выборки разного размера → Велч (безопасный выбор по умолчанию).
  • Есть выбросы / тяжёлые хвосты / данные порядковые → Манн-Уитни.
  • Уверены в нормальности и равенстве дисперсий → можно Стьюдент, но Велч даст тот же результат.

function randn() {
  let u = 0, v = 0;
  while (u === 0) u = Math.random();
  while (v === 0) v = Math.random();
  return Math.sqrt(-2 * Math.log(u)) * Math.cos(2 * Math.PI * v);
}

function generateSample(n, mean, sd, dist) {
  const arr = [];
  for (let i = 0; i < n; i++) {
    let x;
    if (dist === "Нормальное") {
      x = mean + sd * randn();
    } else if (dist === "Экспоненциальное") {
      x = mean + sd * (-Math.log(1 - Math.random()) - 1);
    } else if (dist === "Логнормальное (выбросы)") {
      // exp(N(0,1)) имеет тяжёлый правый хвост; стандартизуем к среднему 0
      // и SD 1 (вычитаем exp(0.5), делим на SD логнормали), затем масштабируем.
      x = mean + sd * (Math.exp(randn()) - 1.6487212707) / 2.1611974159;
    } else {
      x = mean + sd * (Math.random() * 2 * 1.732 - 1.732);
    }
    arr.push(x);
  }
  return arr;
}

function arrMean(a) { return a.reduce((s, x) => s + x, 0) / a.length; }
function arrVar(a) {
  const m = arrMean(a);
  return a.reduce((s, x) => s + (x - m) ** 2, 0) / (a.length - 1);
}

// ── Специальные функции для вычисления p-value ──
function lgamma(z) {
  const c = [76.18009172947146, -86.50532032941677, 24.01409824083091,
             -1.231739572450155, 0.1208650973866179e-2, -0.5395239384953e-5];
  let y = z, x = z, tmp = x + 5.5;
  tmp = (x + 0.5) * Math.log(tmp) - tmp;
  let ser = 1.000000000190015;
  for (let j = 0; j < 6; j++) ser += c[j] / ++y;
  return tmp + Math.log(2.5066282746310005 * ser / x);
}

function incompleteBeta(x, a, b) {
  if (x <= 0) return 0;
  if (x >= 1) return 1;
  const lbeta = lgamma(a) + lgamma(b) - lgamma(a + b);
  const front = Math.exp(Math.log(x) * a + Math.log(1 - x) * b - lbeta) / a;
  // continued fraction
  const MAXIT = 200, EPS = 3e-7, FPMIN = 1e-30;
  const qab = a + b, qap = a + 1, qam = a - 1;
  let c = 1, d = 1 - qab * x / qap;
  if (Math.abs(d) < FPMIN) d = FPMIN;
  d = 1 / d;
  let h = d;
  for (let m = 1; m <= MAXIT; m++) {
    let m2 = 2 * m;
    let aa = m * (b - m) * x / ((qam + m2) * (a + m2));
    d = 1 + aa * d; if (Math.abs(d) < FPMIN) d = FPMIN;
    c = 1 + aa / c; if (Math.abs(c) < FPMIN) c = FPMIN;
    d = 1 / d; h *= d * c;
    aa = -(a + m) * (qab + m) * x / ((a + m2) * (qap + m2));
    d = 1 + aa * d; if (Math.abs(d) < FPMIN) d = FPMIN;
    c = 1 + aa / c; if (Math.abs(c) < FPMIN) c = FPMIN;
    d = 1 / d; const del = d * c; h *= del;
    if (Math.abs(del - 1) < EPS) break;
  }
  return front * h;
}

function tCDF(t, df) {
  const x = df / (df + t * t);
  return 1 - 0.5 * incompleteBeta(x, df / 2, 0.5);
}

function normCDF(z) {
  const t = 1 / (1 + 0.2316419 * Math.abs(z));
  const d = 0.3989423 * Math.exp(-z * z / 2);
  const p = d * t * (0.3193815 + t * (-0.3565638 + t * (1.7814779 + t * (-1.8212560 + t * 1.3302744))));
  return z >= 0 ? 1 - p : p;
}

// ── Тесты ──
function pStudent(a, b) {
  const n1 = a.length, n2 = b.length;
  const m1 = arrMean(a), m2 = arrMean(b);
  const v1 = arrVar(a), v2 = arrVar(b);
  const sp = Math.sqrt(((n1 - 1) * v1 + (n2 - 1) * v2) / (n1 + n2 - 2));
  if (sp === 0) return 1;
  const t = (m1 - m2) / (sp * Math.sqrt(1 / n1 + 1 / n2));
  return 2 * (1 - tCDF(Math.abs(t), n1 + n2 - 2));
}

function pWelch(a, b) {
  const n1 = a.length, n2 = b.length;
  const m1 = arrMean(a), m2 = arrMean(b);
  const v1 = arrVar(a), v2 = arrVar(b);
  const se = Math.sqrt(v1 / n1 + v2 / n2);
  if (se === 0) return 1;
  const t = (m1 - m2) / se;
  const df = (v1 / n1 + v2 / n2) ** 2 /
    ((v1 / n1) ** 2 / (n1 - 1) + (v2 / n2) ** 2 / (n2 - 1));
  return 2 * (1 - tCDF(Math.abs(t), Math.max(1, df)));
}

function pMannWhitney(a, b) {
  const n1 = a.length, n2 = b.length;
  let U1 = 0;
  for (let i = 0; i < n1; i++)
    for (let j = 0; j < n2; j++) {
      if (a[i] > b[j]) U1++;
      else if (a[i] === b[j]) U1 += 0.5;
    }
  const U = Math.min(U1, n1 * n2 - U1);
  const mu = n1 * n2 / 2;
  const sigma = Math.sqrt(n1 * n2 * (n1 + n2 + 1) / 12);
  if (sigma === 0) return 1;
  // Поправка на непрерывность: дискретную статистику U приближаем
  // непрерывным нормальным распределением, поэтому вычитаем 0.5 из |U − μ|
  // (clamp до 0, чтобы при U == μ не уйти в минус).
  const z = Math.max(0, Math.abs(U - mu) - 0.5) / sigma;
  return 2 * (1 - normCDF(z));
}

// ── Основная симуляция ──
simResult = {
  const { n1, n2, sd1, sd2, delta_mean, alpha, n_sim, distrib } = simConfig;
  const pSt = [], pWe = [], pMW = [];

  for (let i = 0; i < n_sim; i++) {
    const a = generateSample(n1, 0, sd1, distrib);
    const b = generateSample(n2, delta_mean, sd2, distrib);
    pSt.push(pStudent(a, b));
    pWe.push(pWelch(a, b));
    pMW.push(pMannWhitney(a, b));
  }

  const rateSt = pSt.filter(p => p < alpha).length / n_sim;
  const rateWe = pWe.filter(p => p < alpha).length / n_sim;
  const rateMW = pMW.filter(p => p < alpha).length / n_sim;

  return { pSt, pWe, pMW, rateSt, rateWe, rateMW, alpha, delta_mean };
}

Разбор сценариев

Сценарии делятся на два типа: оценка ошибки первого рода при верности нулевой гипотезы и оценка мощности, когда нулевая гипотеза не верна. Для краткости можно это назвать искусственным A/A и A/B тестом.

NoteA/A vs A/B
  • A/A-тест (Δ = 0) – обе группы взяты из генеральных совокупностей с одинаковыми средними. Нулевая гипотеза о равенстве средних верна, реального эффекта нет, поэтому отклонение нулевой гипотезы – это ошибка I рода. Здесь мы проверяем, держит ли тест заявленный уровень α.
  • A/B-тест (Δ > 0) – средние групп (истинные средние генеральных совокупностей) действительно различаются. Здесь мы измеряем мощность: как часто тест замечает реальный эффект.

Помните: мощность (A/B) имеет смысл сравнивать между тестами только тогда, когда они одинаково держат α в A/A. Иначе «высокая мощность» может быть просто следствием завышенной ошибки I рода.

A/A-тесты — контроль ошибки I рода

Сценарий 1: H₀ верна, размер выборок и дисперсии равны

Установите: n₁ = n₂ = 15, SD₁ = SD₂ = 1, Δ = 0.

Все три теста должны давать долю ошибок первого рода ≈ \(alpha\). Это базовая проверка: тест работает корректно, если не находит различий там, где их нет.

TipЧто наблюдаем

Все три теста держат α на заданном уровне. Гистограммы p-value близки к равномерному распределению.

Сценарий 2: H₀ верна, размеры выборок равны, дисперсии разные

Установите: n₁ = n₂ = 15, SD₁ = 1, SD₂ = 3, Δ = 0.

При равных размерах выборок классический тест Стьюдента справляется с неравенством дисперсий. Тоже самое было в статье для больших выборок.

TipЧто наблюдаем

Все три теста близки к α = 5%. Неравенство дисперсий не сильно влияет на характеристики теста Стьюдента при равных размерах выборок.

Сценарий 3: Разные дисперсии, разные n, при этом в меньшей выборке дисперсия больше

Установите: n₁ = 30, n₂ = 8, SD₁ = 1, SD₂ = 3, Δ = 0.

Это пример, где тест Стьюдента начинает работать хуже: маленькая выборка с большой дисперсией. В статье для больших выборок (9000 vs 1000) Стьюдент давал до 24% ложных срабатываний. На малых выборках эффект тоже заметен.

WarningЧто наблюдаем

Тест Стьюдента сильно завышает ошибку I рода — в этом сценарии около 25% вместо 5%. Велч держит α (≈ 5%).

Манн-Уитни тоже даёт повышенную долю ложных срабатываний (≈ 13%), но по другой причине: при разных дисперсиях формы распределений различаются, а значит нулевая гипотеза Манна-Уитни (\(P(X>Y)=0.5\)) нарушена даже при равных средних (см. оговорку в разделе с формулой).

Попробуйте усилить дисбаланс: n₁ = 40, n₂ = 5, SD₂ = 4 — и увидите, как Стьюдент совсем ломается: доля ложных срабатываний подскакивает примерно до 40%.

Сценарий 4: Ненормальное распределение (Δ = 0)

Установите: n₁ = n₂ = 15, SD₁ = SD₂ = 1, Δ = 0, распределение = Экспоненциальное.

Экспоненциальное распределение сильно асимметрично. Как справятся тесты при проверке ошибки I рода?

TipЧто наблюдаем

При равных n все три теста обычно держатся в пределах нормы даже на малых выборках — равные размеры групп компенсируют асимметрию распределения. Но это именно заслуга симметрии сценария, а не общая робастность: стоит сделать n неравными, и контроль α перестаёт быть гарантированным.

Причём «плывёт» здесь, что неожиданно, в первую очередь Велч, а не Стьюдент. Установите экспоненциальное распределение, n₁ = 30, n₂ = 8, Δ = 0: Стьюдент держится около 5%, а Велч становится либеральным (≈ 7% вместо 5%). На сильно асимметричных данных «защитные» свойства Велча уже не работают.

Вывод: при выраженной асимметрии ни один из t-тестов не является надёжной защитой — это случай для Манна-Уитни (см. сценарий 5).

A/B-тесты — мощность

Сценарий 5: Есть реальный эффект

Установите: n₁ = n₂ = 15, SD₁ = SD₂ = 1, Δ = 1.

Теперь H0 неверна: средние в генеральной совокупности различаются. Мы смотрим мощность – в какой доле случаев статистический тест отклонил нулевую гипотезу.

TipЧто наблюдаем

При Δ = 1 и n = 15 мощность всех тестов ~ 70–75%. Увеличьте n до 25 — и мощность вырастет до > 90%.

Манн-Уитни на нормальных данных немного уступает параметрическим тестам в мощности — это неудивительно, так как перевод в ранги обычно приводит к уменьшению мощности.

Переключитесь на логнормальное (выбросы) при Δ = 0.5: на данных с тяжёлым хвостом разрыв огромный — мощность Манна-Уитни около 75% против ~42% у обоих t-тестов. Именно выбросы, а не «ненормальность» сами по себе, «ослепляют» t-тесты: одно экстремальное значение сильно раздувает выборочную дисперсию, и t-статистика проседает. Ранговый Манн-Уитни к таким выбросам устойчив.

Зависимость ошибки I рода от дисбаланса выборок

Установите SD₁ = 1, SD₂ = 3, Δ = 0 и двигайте слайдер n₂ от 5 до 50 при фиксированном n₁ = 30. Вы увидите:

  • При n₂ ≈ n₁: все тесты в норме
  • При n₂ << n₁ (маленькая выборка с большой дисперсией): Стьюдент завышает α
  • При n₂ >> n₁ (большая выборка с большой дисперсией): Стьюдент даже занижает α (консервативен)

Тест Велча стабилен во всех случаях.

Но в гетероскедастичных сценариях «высокая мощность» Стьюдента иллюзорна: она достигается за счёт нарушения уровня α (часть «находок» — ложные срабатывания), поэтому сравнивать её с честной мощностью Велча нельзя (см. оговорку ниже).

Рекомендации:

  1. По умолчанию используйте тест Велча — он надёжен во всех разобранных ситуациях, как на больших, так и на малых выборках
  2. Манн-Уитни стоит применять, когда есть основания сомневаться в нормальности распределения — особенно при выбросах и тяжёлых хвостах (логнормальные данные, время отклика, деньги). Именно там он заметно мощнее t-тестов.
  3. Классический тест Стьюдента имеет смысл только когда вы уверены в равенстве дисперсий — но если вы в этом уверены, Велч всё равно даст тот же результат. Так зачем рисковать?
  4. Не используйте Манн-Уитни как «защиту» от разных дисперсий. Он не лечит гетероскедастичность, а реагирует на неё ложными срабатываниями (см. выше). Разные дисперсии — это про Велча, а не про непараметрику.
WarningВелч и мощность: важная оговорка

Когда дисперсии сильно неравны (SD₂/SD₁ > 3–5) и группы несбалансированы, тест Велча может показывать меньшую мощность, чем Стьюдент. Проверьте сами: установите n₁ = 50, SD₁ = 0.5, n₂ = 15, SD₂ = 5, Δ = 2.5.

Это не недостаток Велча — это честность. Малая шумная группа даёт высокую неопределённость в оценке среднего, и Велч корректно это отражает через уменьшенные степени свободы (df ≈ 14 вместо 63). «Высокая мощность» Стьюдента в таких сценариях достигается за счёт некорректного пулирования дисперсий и фактического нарушения уровня α — то есть часть его «находок» является ложными срабатываниями.

А как же позиция «Велч не нужен по умолчанию»?

Есть весомая точка зрения, что менять Стьюдента на Велча по умолчанию не стоит (см., например, разбор от X5 Tech). Аргументы такие:

  1. Велч урезает степени свободы и теряет мощность.
  2. Чистая гетероскедастичность редка (аргумент Sawilowsky): «мы никогда не встречали воздействия, которое меняет дисперсии, оставляя средние строго равными» — на практике эффект двигает и среднее, и разброс, так что сценарии A/A с разными SD при Δ = 0 искусственны.
  3. На больших сбалансированных выборках (классический A/B-тест 50/50) Стьюдент и так контролирует α при любой дисперсии, поэтому заменять его не на что.

Это честные аргументы, но они не противоречат выводам выше — они про другую область применения:

  • Потеря мощности у Велча почти нулевая при равных n. В симуляциях при n₁ = n₂ разница мощности Стьюдента и Велча — доли процентного пункта, даже при сильно неравных дисперсиях. Заметная потеря возникает только в углу «малые n + дисбаланс + сильно неравные SD» — но именно там у Стьюдента нарушается α, так что честно выиграть им всё равно нельзя (см. оговорку выше).
  • A/B-тесты vs малые выборки. В продуктовых A/B-тестах выборки большие, а сплит контролируемый (50/50) — там Стьюдент и Велч практически тождественны, и спор беспредметен. Этот пост — про малые неконтролируемые выборки в биологии и медицине, где исследователь не управляет ни балансом групп, ни их дисперсиями. Именно здесь Велч страхует от реальных провалов.

Иными словами: если вы уверены в равных n и равных дисперсиях — Стьюдент и Велч дадут одно и то же. Как только эта уверенность пропадает (а на малых выборках это норма), Велч оказывается безопаснее почти бесплатно.

ImportantГлавный вывод

Аргументы «за Велч» из предыдущего поста полностью подтверждаются и на малых выборках. Проблема Стьюдента с неравными дисперсиями и разными n — не артефакт больших выборок, она проявляется даже при n = 5–30.

Контраргумент «Велч теряет мощность» справедлив в основном для больших сбалансированных A/B-тестов; на малых неконтролируемых выборках цена этой «потери» близка к нулю, а защита от завышенной ошибки I рода — реальна.
