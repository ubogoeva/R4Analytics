Введение

В предыдущем посте я разбирала как работает тест Стьюдента и тест Велча на больших выборках (n = 1000–10000). Краткий вывод: тест Велча надёжнее при неравных дисперсиях и разных размерах выборок, так как лучше контролирует ошибку первого рода.

Но в научных исследованиях, например в биологии, медицине выборки обычно не такие большие, может быть всего 5–30 наблюдений на группу. В прошлый раз обещала рассмотреть отдельно, как работают тесты на малых выборках. В этот раз я подготовила интерактивные симуляции, которые работают прямо в браузере. Можно менять параметры и наблюдать, как это влияет на ошибку I рода и мощность тестов.

NoteНапоминание

Ошибка I рода — вероятность найти различия, когда их нет (ложноположительный результат). Должна быть ≈ заданному уровню α (обычно 0.05). Подробнее писала здесь.

Мощность (1−β) — вероятность найти различия, когда они действительно есть. Чем выше, тем лучше (обычно стараются иметь уровень мощности не меньше 0.8).

Надежный статистический тест должен контролировать ошибку I рода на уровне значимости α и при этом обладать высокой мощностью для обнаружения реального эффекта.

NoteНемного формул (нажмите, чтобы развернуть)

Тест Стьюдента

Вычисление t-статистики:

\[ t = \frac{\overline{X}_1 - \overline{X}_2}{s_p\sqrt{\frac{1}{n_1} + \frac{1}{n_2}}}, \quad s_p = \sqrt{\frac{(n_1 - 1)s_1^2 + (n_2 - 1)s_2^2}{n_1 + n_2 - 2}} \]

Количество степеней свободы: \(df = n_1 + n_2 - 2\)

Тест Велча

Вычисление t-статистики:

\[ t = \frac{\overline{X}_1 - \overline{X}_2}{\sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}} \]

Количество степеней свободы:

\[ df = \frac{\left(\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}\right)^2}{\frac{(s_1^2/n_1)^2}{n_1-1} + \frac{(s_2^2/n_2)^2}{n_2-1}} \]

Тест Манна-Уитни

Непараметрический тест, основанный на рангах. Не требует нормальности распределения выборочных средних. Статистика \(U\) считается по числу пар \((x_i, y_j)\), где \(x_i > y_j\), и при \(n_1, n_2 > 5\) сопоставляется с нормальным приближением:

\[ z = \frac{|U - \frac{n_1 n_2}{2}| - 0.5}{\sqrt{\frac{n_1 n_2 (n_1 + n_2 + 1)}{12}}} \]

В числителе — поправка на непрерывность (−0.5): так как дискретная ранговая статистика приближается непрерывным распределением. На очень малых выборках (n ≈ 5–6) из-за этой поправки и общей дискретности данных нормальное приближение теста становится довольно консервативным (фактическая доля ложных срабатываний падает ниже заявленного \(\alpha\)).

Тест Бруннера-Мюнцеля

Робастный ранговый тест, который в отличие от Манна-Уитни, не требует одинаковых дисперсий и форм распределений (см. Brunner & Munzel, 2000). Каждое наблюдение ранжируется и в объединённой выборке (\(R_{ki}\)), и внутри своей группы (\(R^{(k)}_{ki}\)). Статистика:

\[ W = \frac{n_1 n_2 \,(\overline{R}_{2} - \overline{R}_{1})}{(n_1 + n_2)\sqrt{n_1 S_1^2 + n_2 S_2^2}}, \quad S_k^2 = \frac{1}{n_k - 1}\sum_{i=1}^{n_k}\left(R_{ki} - R^{(k)}_{ki} - \overline{R}_{k} + \tfrac{n_k+1}{2}\right)^2 \]

где \(\overline{R}_{k}\) — средний ранг группы \(k\) в объединённой выборке. Ключевое отличие от Манна-Уитни: дисперсия рангов \(S_k^2\) оценивается отдельно для каждой группы, поэтому тест устойчив к гетероскедастичности. Статистика \(W\) сравнивается с распределением Стьюдента со степенями свободы по Саттертуэйту (как у теста Велча):

\[ df = \frac{\left(n_1 S_1^2 + n_2 S_2^2\right)^2}{\frac{(n_1 S_1^2)^2}{n_1 - 1} + \frac{(n_2 S_2^2)^2}{n_2 - 1}} \]

ImportantНулевая гипотеза Манна-Уитни не о равенстве средних

Напомню, что тест Манна-Уитни не сравнивает средние, однако из-за восприятия как непараметрического аналога теста Стьюдента может сложиться такое впечатление. Его нулевая гипотеза — это \(P(X > Y) = 0.5\), то есть «значения из одной группы не склонны быть систематически больше значений из другой». Только при жестком допущении одинаковой формы и дисперсии распределений этот тест становится эквивалентен сравнению медиан или оценке величины сдвига (location shift).

Практическое следствие: Если у групп разные дисперсии, стандартный аппарат теста ломается. Формула знаменателя (стандартной ошибки рангов) требует полной идентичности форм распределений (\(F = G\)). При гетероскедастичности эта оценка становится неверной, тест занижает реальную ошибку и начинает завышать долю ложных срабатываний в A/A-тестах.

Отсюда важный антипаттерн. Многие при виде неравных дисперсий, ненормального распределения данных переходят на непараметрику, считая её более устойчивой. Но Манн-Уитни не решает проблему гетероскедастичности, он тоже подвержен ей и даёт ложные срабатывания при равных средних. Если дисперсии разные, правильный инструмент — тест Велча, а для сравнения ранговых распределений — тест Бруннера-Мюнцеля (Brunner-Munzel test), который корректно пересчитывает стандартную ошибку для каждой группы отдельно (формула теста выше под катом).

function randn() {
  let u = 0, v = 0;
  while (u === 0) u = Math.random();
  while (v === 0) v = Math.random();
  return Math.sqrt(-2 * Math.log(u)) * Math.cos(2 * Math.PI * v);
}

function generateSample(n, mean, sd, dist) {
  const arr = [];
  for (let i = 0; i < n; i++) {
    let x;
    if (dist === "Нормальное") {
      x = mean + sd * randn();
    } else if (dist === "Экспоненциальное") {
      x = mean + sd * (-Math.log(1 - Math.random()) - 1);
    } else if (dist === "Логнормальное (выбросы)") {
      // exp(N(0,1)) имеет тяжёлый правый хвост; стандартизуем к среднему 0
      // и SD 1 (вычитаем exp(0.5), делим на SD логнормали), затем масштабируем.
      x = mean + sd * (Math.exp(randn()) - 1.6487212707) / 2.1611974159;
    } else {
      x = mean + sd * (Math.random() * 2 * 1.732 - 1.732);
    }
    arr.push(x);
  }
  return arr;
}

// ── Вспомогательные функции ──
function arrMean(a) { return a.reduce((s, x) => s + x, 0) / a.length; }
function arrVar(a) {
  const m = arrMean(a);
  return a.reduce((s, x) => s + (x - m) ** 2, 0) / (a.length - 1);
}

// ── Специальные функции для вычисления p-value ──
function lgamma(z) {
  const c = [76.18009172947146, -86.50532032941677, 24.01409824083091,
             -1.231739572450155, 0.1208650973866179e-2, -0.5395239384953e-5];
  let y = z, x = z, tmp = x + 5.5;
  tmp = (x + 0.5) * Math.log(tmp) - tmp;
  let ser = 1.000000000190015;
  for (let j = 0; j < 6; j++) ser += c[j] / ++y;
  return tmp + Math.log(2.5066282746310005 * ser / x);
}

// Непрерывная дробь Лентца для неполной бета-функции
function betacf(x, a, b) {
  const MAXIT = 200, EPS = 3e-7, FPMIN = 1e-30;
  const qab = a + b, qap = a + 1, qam = a - 1;
  let c = 1, d = 1 - qab * x / qap;
  if (Math.abs(d) < FPMIN) d = FPMIN;
  d = 1 / d;
  let h = d;
  for (let m = 1; m <= MAXIT; m++) {
    let m2 = 2 * m;
    let aa = m * (b - m) * x / ((qam + m2) * (a + m2));
    d = 1 + aa * d; if (Math.abs(d) < FPMIN) d = FPMIN;
    c = 1 + aa / c; if (Math.abs(c) < FPMIN) c = FPMIN;
    d = 1 / d; h *= d * c;
    aa = -(a + m) * (qab + m) * x / ((a + m2) * (qap + m2));
    d = 1 + aa * d; if (Math.abs(d) < FPMIN) d = FPMIN;
    c = 1 + aa / c; if (Math.abs(c) < FPMIN) c = FPMIN;
    d = 1 / d; const del = d * c; h *= del;
    if (Math.abs(del - 1) < EPS) break;
  }
  return h;
}

function incompleteBeta(x, a, b) {
  if (x <= 0) return 0;
  if (x >= 1) return 1;
  const front = Math.exp(lgamma(a + b) - lgamma(a) - lgamma(b)
    + a * Math.log(x) + b * Math.log(1 - x));
  // Swap-симметрия: непрерывная дробь точна при x < (a+1)/(a+b+2);
  // иначе считаем через I_x(a,b) = 1 − I_{1−x}(b,a) (важно для малых |t|).
  if (x < (a + 1) / (a + b + 2)) {
    return front * betacf(x, a, b) / a;
  } else {
    return 1 - front * betacf(1 - x, b, a) / b;
  }
}

function tCDF(t, df) {
  const x = df / (df + t * t);
  return 1 - 0.5 * incompleteBeta(x, df / 2, 0.5);
}

function normCDF(z) {
  const t = 1 / (1 + 0.2316419 * Math.abs(z));
  const d = 0.3989423 * Math.exp(-z * z / 2);
  const p = d * t * (0.3193815 + t * (-0.3565638 + t * (1.7814779 + t * (-1.8212560 + t * 1.3302744))));
  return z >= 0 ? 1 - p : p;
}

// ── Тесты ──
function pStudent(a, b) {
  const n1 = a.length, n2 = b.length;
  const m1 = arrMean(a), m2 = arrMean(b);
  const v1 = arrVar(a), v2 = arrVar(b);
  const sp = Math.sqrt(((n1 - 1) * v1 + (n2 - 1) * v2) / (n1 + n2 - 2));
  if (sp === 0) return 1;
  const t = (m1 - m2) / (sp * Math.sqrt(1 / n1 + 1 / n2));
  return 2 * (1 - tCDF(Math.abs(t), n1 + n2 - 2));
}

function pWelch(a, b) {
  const n1 = a.length, n2 = b.length;
  const m1 = arrMean(a), m2 = arrMean(b);
  const v1 = arrVar(a), v2 = arrVar(b);
  const se = Math.sqrt(v1 / n1 + v2 / n2);
  if (se === 0) return 1;
  const t = (m1 - m2) / se;
  const df = (v1 / n1 + v2 / n2) ** 2 /
    ((v1 / n1) ** 2 / (n1 - 1) + (v2 / n2) ** 2 / (n2 - 1));
  return 2 * (1 - tCDF(Math.abs(t), Math.max(1, df)));
}

function pMannWhitney(a, b) {
  const n1 = a.length, n2 = b.length;
  let U1 = 0;
  for (let i = 0; i < n1; i++)
    for (let j = 0; j < n2; j++) {
      if (a[i] > b[j]) U1++;
      else if (a[i] === b[j]) U1 += 0.5;
    }
  const U = Math.min(U1, n1 * n2 - U1);
  const mu = n1 * n2 / 2;
  const sigma = Math.sqrt(n1 * n2 * (n1 + n2 + 1) / 12);
  if (sigma === 0) return 1;
  // Поправка на непрерывность: дискретную статистику U приближаем
  // непрерывным нормальным распределением, поэтому вычитаем 0.5 из |U − μ|
  // (clamp до 0, чтобы при U == μ не уйти в минус).
  const z = Math.max(0, Math.abs(U - mu) - 0.5) / sigma;
  return 2 * (1 - normCDF(z));
}

// Ранги с усреднением для совпадений (mid-ranks), 1-based
function rankdata(arr) {
  const n = arr.length;
  const idx = Array.from({ length: n }, (_, i) => i).sort((p, q) => arr[p] - arr[q]);
  const ranks = new Array(n);
  let i = 0;
  while (i < n) {
    let j = i;
    while (j + 1 < n && arr[idx[j + 1]] === arr[idx[i]]) j++;
    const avg = (i + j + 2) / 2; // средний ранг группы совпадений
    for (let k = i; k <= j; k++) ranks[idx[k]] = avg;
    i = j + 1;
  }
  return ranks;
}

// Тест Бруннера-Мюнцеля: робастный аналог Манна-Уитни, не требующий
// равенства дисперсий/форм. Использует t-приближение со степенями
// свободы по Саттертуэйту (как у Велча).
function pBrunnerMunzel(a, b) {
  const n1 = a.length, n2 = b.length;
  if (n1 < 2 || n2 < 2) return 1;
  const rc = rankdata(a.concat(b));        // ранги в объединённой выборке
  const rcx = rc.slice(0, n1), rcy = rc.slice(n1);
  const rx = rankdata(a), ry = rankdata(b); // ранги внутри своих групп
  const mrcx = arrMean(rcx), mrcy = arrMean(rcy);
  const mrx = arrMean(rx), mry = arrMean(ry);
  let Sx = 0;
  for (let i = 0; i < n1; i++) Sx += (rcx[i] - rx[i] - mrcx + mrx) ** 2;
  Sx /= (n1 - 1);
  let Sy = 0;
  for (let j = 0; j < n2; j++) Sy += (rcy[j] - ry[j] - mrcy + mry) ** 2;
  Sy /= (n2 - 1);
  const denom = (n1 + n2) * Math.sqrt(n1 * Sx + n2 * Sy);
  if (denom === 0) return 1;
  const w = n1 * n2 * (mrcy - mrcx) / denom;
  const dfDen = (n1 * Sx) ** 2 / (n1 - 1) + (n2 * Sy) ** 2 / (n2 - 1);
  if (dfDen === 0) return 1;
  const df = (n1 * Sx + n2 * Sy) ** 2 / dfDen;
  return 2 * (1 - tCDF(Math.abs(w), Math.max(1, df)));
}

Разбор надежности тестов

Для анализа надежности тестов нужно проверить два пункта: оценка ошибки первого рода при верности нулевой гипотезы и оценка мощности, когда нулевая гипотеза не верна. Для краткости можно это назвать искусственным A/A и A/B тестом.

NoteA/A vs A/B
  • A/A-тест (\(Δ = 0\)) – обе группы взяты из генеральных совокупностей с одинаковыми средними. Нулевая гипотеза о равенстве средних верна, реального эффекта нет, поэтому отклонение нулевой гипотезы – это ошибка I рода. Здесь мы проверяем, держит ли тест заявленный уровень α.
  • A/B-тест (\(Δ \neq 0\)) – средние групп (истинные средние генеральных совокупностей) действительно различаются. Здесь мы измеряем мощность: как часто тест замечает реальный эффект.

Помните: мощность имеет смысл сравнивать между тестами только тогда, когда они одинаково держат α в A/A. Иначе высокая мощность может быть просто следствием завышенной ошибки I рода.

A/A-тесты — контроль ошибки I рода

Сценарий 1: H₀ верна, размер выборок и дисперсии равны

Установите: n₁ = n₂ = 15, SD₁ = SD₂ = 1, Δ = 0.

Все тесты должны давать долю ошибок первого рода ≈ \(alpha\). Это базовая проверка: тест работает корректно, если не находит различий там, где их нет.

TipЧто наблюдаем

Все четыре теста держат α на заданном уровне. Гистограммы p-value близки к равномерному распределению.

Сценарий 2: H₀ верна, размеры выборок равны, дисперсии разные

Установите: n₁ = n₂ = 15, SD₁ = 1, SD₂ = 3, Δ = 0.

При равных размерах выборок классический тест Стьюдента справляется с неравенством дисперсий. Тоже самое было в статье для больших выборок.

TipЧто наблюдаем

Все четыре теста близки к заданной α. Неравенство дисперсий не сильно влияет на характеристики теста Стьюдента при равных размерах выборок. Непараметрические тесты тоже работают корректно.

Сценарий 3: Разные дисперсии, разные n, при этом в меньшей выборке дисперсия больше

Установите: n₁ = 30, n₂ = 8, SD₁ = 1, SD₂ = 3, Δ = 0.

Это пример, где тест Стьюдента начинает работать хуже: маленькая выборка с большой дисперсией. В статье для больших выборок (9000 vs 1000) Стьюдент давал до 24% ложных срабатываний. На малых выборках эффект тоже заметен.

WarningЧто наблюдаем

Тест Стьюдента сильно завышает ошибку I рода — в этом сценарии около 25% вместо 5%. Велч держит α (≈ 5%).

Манн-Уитни тоже даёт повышенную долю ложных срабатываний (≈ 13%), но по другой причине: при разных дисперсиях формы распределений различаются, а значит нулевая гипотеза Манна-Уитни (\(P(X>Y)=0.5\)) нарушена даже при равных средних (см. оговорку выше).

А вот тест Бруннера-Мюнцеля здесь держится заметно лучше Манна-Уитни (≈ 6% против 13%): он не предполагает одинаковых форм распределений и пересчитывает стандартную ошибку для каждой группы отдельно, поэтому многие рекомендуют использовать именно этот тест.

Рекомендую отрегулировать n₂ при фиксированных n₁ = 30, SD₁ = 1, SD₂ = 3, Δ = 0 — и увидите, как ведёт себя Стьюдент в зависимости от дисбаланса:

  • n₂ ≈ n₁: все тесты в норме;
  • n₂ << n₁ (маленькая выборка с большой дисперсией): Стьюдент завышает α — вплоть до ~40% при n₂ = 5, SD₂ = 4;
  • n₂ >> n₁ (большая выборка с большой дисперсией): Стьюдент, наоборот, занижает α, становясь излишне консервативным.

Тест Велча стабилен во всех случаях.

Сценарий 4: Ненормальное распределение (Δ = 0)

Установите: n₁ = n₂ = 15, SD₁ = SD₂ = 1, Δ = 0, распределение = Экспоненциальное.

Экспоненциальное распределение сильно асимметрично. Как справятся тесты при проверке ошибки I рода?

TipЧто наблюдаем

При равных n все три теста обычно держатся в пределах нормы даже на малых выборках — равные размеры групп компенсируют асимметрию распределения.

A/B-тесты — анализ мощности

Сценарий 5: Есть реальный эффект, размеры выборок и дисперсии равны

Установите: n₁ = n₂ = 15, SD₁ = SD₂ = 1, Δ = 1.

Теперь H0 неверна: средние в генеральной совокупности различаются, анализируем мощность теста.

TipЧто наблюдаем

При Δ = 1 и n = 15 мощность всех тестов ~ 70–75%. При увеличении n до 25, мощность вырастет до > 90%.

Манн-Уитни и Бруннер-Мюнцель на нормальных данных немного уступают параметрическим тестам в мощности — это неудивительно, так как перевод в ранги обычно приводит к небольшой потере мощности (здесь MW ≈ 71%, остальные ≈ 74%).

Сценарий 6: Выбросы и тяжёлые хвосты — преимущество ранговых тестов

Установите: n₁ = n₂ = 15, SD₁ = SD₂ = 1, Δ = 0.5, распределение = Логнормальное (выбросы).

TipЧто наблюдаем

Разрыв огромный: мощность Манна-Уитни ≈ 75% и Бруннера-Мюнцеля ≈ 74% против ≈ 43% у обоих t-тестов. Одно экстремальное значение раздувает выборочную дисперсию, и t-статистика проседает. Ранговые тесты к таким выбросам устойчивы.

Это зеркало Сценария 4: там на ненормальных данных мы смотрели ошибку I рода, здесь — мощность. Общий вывод: при выбросах и тяжёлых хвостах выбирайте ранговые тесты (Манн-Уитни или Бруннер-Мюнцель).

Сценарий 7: Мощность при неравных дисперсиях — «честная плата» Велча

Установите: n₁ = 50, SD₁ = 0.5, n₂ = 15, SD₂ = 5, Δ = 2.5.

WarningЧто наблюдаем

Стьюдент показывает высокую мощность (≈ 80%), Велч заметно ниже (≈ 43%), Манн-Уитни ≈ 58%, Бруннер-Мюнцель ≈ 34%. Кажется, что Стьюдент лучший — но это иллюзия: в этом же сценарии при Δ = 0 (см. Сценарий 3) он завышает ошибку I рода, то есть часть его «находок» — ложные срабатывания. Мощность сравнима между тестами только при одинаково контролируемой α.

Велч же честно отражает большую неопределённость маленькой шумной группы через уменьшенные степени свободы (df ≈ 14 вместо 63). Низкая мощность здесь — не дефект теста, а корректная оценка: реально надёжно поймать эффект при такой комбинации (мало наблюдений + огромная дисперсия во второй группе) объективно трудно.

Рекомендации:

  1. По умолчанию используйте тест Велча — он надёжен во всех разобранных ситуациях, как на больших, так и на малых выборках
  2. Манн-Уитни стоит применять, когда есть основания сомневаться в нормальности распределения — особенно при выбросах и тяжёлых хвостах (логнормальные данные, время отклика, деньги). Именно там он заметно мощнее t-тестов.
  3. Классический тест Стьюдента имеет смысл только когда вы уверены в равенстве дисперсий — но если вы в этом уверены, Велч всё равно даст тот же результат. Так зачем рисковать?
  4. Не используйте Манн-Уитни как «защиту» от разных дисперсий. Он не лечит гетероскедастичность, а реагирует на неё ложными срабатываниями (см. выше). Разные дисперсии — это про Велча, а не про непараметрику.
  5. Бруннер-Мюнцель — если нужна непараметрика и дисперсии/формы распределений разные. Он сохраняет устойчивость рангового подхода к выбросам (как Манн-Уитни), но при этом держит α при гетероскедастичности (как Велч) — фактически «ранговый аналог Велча».

А как же позиция «Велч не нужен по умолчанию»?

Есть точка зрения, что менять Стьюдента на Велча по умолчанию не стоит (см., например, разбор от X5 Tech). Аргументы такие:

  1. Велч урезает степени свободы и теряет мощность.
  2. Чистая гетероскедастичность редка (аргумент Sawilowsky): «мы никогда не встречали воздействия, которое меняет дисперсии, оставляя средние строго равными» — на практике эффект двигает и среднее, и разброс, так что сценарии A/A с разными SD при Δ = 0 искусственны.
  3. На больших сбалансированных выборках (классический A/B-тест 50/50) Стьюдент и так контролирует α при любой дисперсии, поэтому заменять его не на что.

Это все валидно, но не противоречит выводам выше — они про другую область применения:

  • Потеря мощности у Велча почти нулевая при равных n. В симуляциях при n₁ = n₂ разница мощности Стьюдента и Велча — доли процентного пункта, даже при сильно неравных дисперсиях. Заметная потеря возникает только в углу «малые n + дисбаланс + сильно неравные SD» — но именно там у Стьюдента нарушается α, так что честно выиграть им всё равно нельзя (см. оговорку выше).
  • A/B-тесты vs малые выборки. В продуктовых A/B-тестах выборки большие, а сплит контролируемый (50/50) — там Стьюдент и Велч практически тождественны, и спор беспредметен. Этот пост — про малые неконтролируемые выборки в биологии и медицине, где исследователь не управляет ни балансом групп, ни их дисперсиями. Именно здесь Велч страхует от реальных провалов.

Иными словами: если вы уверены в равных n и равных дисперсиях — Стьюдент и Велч дадут одно и то же. Как только эта уверенность пропадает (а на малых выборках это норма), Велч оказывается безопаснее почти бесплатно.

ImportantГлавный вывод

Аргументы «за Велч» из предыдущего поста полностью подтверждаются и на малых выборках. Проблема Стьюдента с неравными дисперсиями и разными n — не артефакт больших выборок, она проявляется даже при n = 5–30.

Контраргумент «Велч теряет мощность» справедлив в основном для больших сбалансированных A/B-тестов; на малых неконтролируемых выборках цена этой «потери» близка к нулю, а защита от завышенной ошибки I рода — реальна.
